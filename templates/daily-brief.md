# Template — Daily brief (~7:30am IST, half a page)

The routine fills this each morning after reading Outlook live. Keep it to **one screen**.
Order is fixed: what's on him → what's stuck with others → what's chasing him → deadlines →
feedback ask.

```
# Daily Brief — {Weekday}, {D Month YYYY}
*Your loops, your clocks, this week's deadlines. ~2-min read.*

### 🛑 Blocked on you
{1–3 items where nothing moves until Pratekk acts. Each: what it is, who's waiting, the
clock ("since {date} ({N days})"), and the single action that unblocks it. If none: say
"Nothing is parked on you today — rare, enjoy it."}

### ⏳ Delegated & gone quiet
{Open loops he handed off. Each: **Owner — thing.** Asked {date} ({N days}). Confidence
{high/med/low}. Pull from Sent-Items delegation syntax (++ @Name, Looping in, request X to).
Cap at ~5, freshest-risk first. Fresh (0–1 day) items marked "tracking", not "quiet".}

### 📬 Circling back to you
{Inbound "just following up / circling back / slipped through" on threads his side went
quiet on. Each: who, original date, days quiet. Filter out vendor/cold-outreach spam of
this shape. Omit the section if empty.}

### 📅 Regulatory deadlines this week
{Hard-deadline regulatory/compliance items landing within 7 days, from docs/03-regulatory-map.md
+ live inbox + Junk sweep. Each: due date, item, owner/state. Always run the Junk sweep;
if clean, add the reassurance line.}

*{One-line good-news reassurance when Junk is clean of regulatory risk.}*

---
**Was this useful?** Reply one word:
**👍 keep it** · **✂️ shorter** · **🎯 wrong stuff** · **more: [what you want added]**
*Your answer tunes tomorrow's brief.*
```

## Rules
- **Half a page max.** If it's longer, cut the lowest-confidence "quiet" items first.
- **Every item names an owner and a clock.** No ownerless, clockless lines.
- **Read live every morning** — inbox + sent + junk + calendar. Never reuse yesterday's
  list without re-checking state.
- **Confidence tags on "quiet" items** until per-thread tracking + WhatsApp land.
- **No auto-send to third parties.** This brief goes to Pratekk only.
- Sweep **Junk** every run — the spam-miss fear is the reason System 1 exists.
